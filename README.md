# Son Hat

Godot 4.3 ile geliştirilen, gece treninde geçen beş vagonluk 2D aksiyon oyunu.

## Android

GitHub Actions'ta **Son Hat Android APK** çalışmasını aç. Başarılı çalışmanın **Artifacts** bölümünden `Son-Hat-Android` arşivini indir. Arşivde test anahtarıyla imzalanan `Son-Hat.apk` bulunur.

## Kaynak proje

`project.godot` dosyasını Godot 4.3 ile aç. Görseller ve sesler depoya dahildir. Bunları yeniden üretmek için `python3 tools/generate_assets.py` komutunu kullan. Android dışa aktarma betiği `tools/export_android.sh` dosyasındadır.
